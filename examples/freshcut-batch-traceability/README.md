# 鲜切水果批次追溯演练与四张可填写表

供应方要求核查一个原料批次，生产已经混批、成品又分送几家门店，质量负责人怎样查全去向、对清数量？这个原创教学包用两批原料、三张加工单讲清批次关系，并提供可直接填写的四张表。全部数字为作者设计的教学假设，不是真实客户数据。

## 下载资料

- [8页PDF预览](./freshcut-traceability.pdf)

四张表分别用于原料批次与到货凭证、加工投入与产出关系、成品流转、演练核对和缺口复测。建议先下载Word，在企业授权下抽取一个批次做内部演练；不要在公开评论上传实际订单、联系方式或客户资料。

## 算例怎样核对

| 层次 | 教学记录 | 核对 |
|---|---|---|
| 原料P1 | T1耗用25kg，T2耗用10kg，结余5kg | 25＋10＋5＝到货40kg |
| 原料P2 | T1耗用15kg，T3耗用12kg，结余3kg | 15＋12＋3＝到货30kg |
| T1加工 | P1的25kg与P2的15kg混用，产出F1为32kg，其余8kg为已记录副产物或工艺损失 | 40＝32＋8 |
| T2加工 | P1投入10kg，产出F2为8kg，其余2kg为已记录副产物或工艺损失 | 10＝8＋2 |
| T3加工 | P2投入12kg，产出F3为9kg，其余3kg为已记录副产物或工艺损失 | 12＝9＋3 |
| 与P1关联的成品 | F1整批32kg与F2整批8kg；在库9kg，已发31kg | 32＋8＝9＋31＝40kg |
| 已发去向 | 门店A为17kg，门店B为14kg | 17＋14＝31kg |

T1混用了P2，不能按P1的配方比例只查F1的一部分；按本例已知关系，把F1整批纳入。P1未加工的原料5kg属于原料层，不加进40kg成品总量。已发货也不等于已签收。

F3在这个算例的已知加工关系里不与P1关联；真实事件有共线、接触、误投料或缺失记录时，不能据此自动排除其他批次，须由有权限的质量负责人继续核查。详细六步演练、四表填写规则和缺口复测见下载资料。

## 使用条件

这是记录组织与内部演练资料，不是食品安全处置、召回、温控、保质期、检验或放行意见。真实异常按企业已批准的程序及适用要求处理；记录齐、数量平都不等于允许销售。内部教学编号不代表GS1编码或认证。

本例18项数量与关系断言经本地复算，Word原生导出PDF为8页，四张表均保留在独立页面。它不是Coze工厂布局技能的运行结果，也不宣称现有商品有追溯或食品安全判断能力；没有新增收费SKU。
