# 仓库盘点时点核对与差异桥接模板

给鲜切原料仓、中央厨房和小型仓库的盘点负责人：先把账和实物还原到同一时刻，再判断数量差异。合成教学算例说明为什么同一批货，错用旧账会得到“多10kg”，对齐时点后却是“少10kg”。

资料为原创教学模板，含AI辅助整理；不是客户结果、Coze调用、WMS接口、库存估值或财务审计。Excel与PDF来自同一主件，不按文件数算多篇内容。

## 先看算例

范围固定为苹果原料A、LOT1批、R01库位、自有货、可用状态、kg。

| 时点 | 实际业务或数据 |
|---|---|
| 9月30日23:59:59 | 底表快照200kg |
| 10月1日07:30 | 收入60kg |
| 07:45 | 领出40kg |
| 08:00 | 统一比较时点T0 |
| 08:10 | 继续领出15kg |
| 08:30 | 实点195kg |

T0应有量 `200+60-40=220`；T0实物回推 `195+15=210`；正确差异 `210-220=-10`。

错用旧账比较 `210-200=+10`，会连差异方向都看反。直接拿晚时点实点与旧账比 `195-200=-5` 也不是同口径差异。

## 四张表怎样用

1. **说明与范围**：填底表、T0、实点三个时刻及数量，固定商品、批次、库位、货主、状态与kg单位。
2. **业务流水**：只登记快照之后至实点之间同范围的实际业务。每笔唯一ID、一个入出方向，保留实际时间、单号、入账状态和证据确认。
3. **时点桥接**：用已核流水推应有量、回推实物，读取差异和守恒检查；不覆盖公式来“调平”。
4. **复核记录**：保留原始差异、复点、原因依据、责任人与审批，系统调整仍按企业制度办理。

模板固定kg、不自动换箱/件，不接入任何库存或财务系统。加工转化、跨批、拆包或状态变化，先补转换依据，不能硬套简单加减。

## 待核不等于零

已填数据中的空数量、负数、错单位、重复ID、错范围、缺证据和时点冲突会挡住数字结论。显式填0与空白不同。

**整笔流水没登记，模板不能凭空发现。** 本例删去40kg领料但仍声称“已核齐”，会误算出-50kg；只有人工核证窗口完整性后，才可选“已核齐”。拿不全就留“未核齐”，必要时缩小范围重新盘点。

没有差异也不自动证明现场记录完整；有差异也不证明损耗、偷盗或个人责任。该模板不自动批准报损、调账或出库。
