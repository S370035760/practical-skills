设备三态核对：交接表与四组真实本地实验摘要
LeanEdge · 2026-10-14

适合谁：鲜切水果加工车间或类似空间方案评审的现场负责人、建模人员和复核者。
要解决的窄问题：参考平面图与一个已可靠编号的模型，设备位置、数量及保留通道有没有对得上。

本目录仅公开表格、方法说明与结果摘要。不含私有布局一致性原型、已售Coze技能源码、Blender模型或客户数据。

文件：
device-review-template.csv：17列空白核对表。先逐台填写原图参考与模型实测，不知道的值留空并说明，不填0。
case-results.csv：4组虚构300㎡鲜切样例的实际本地结果，不是客户案例、任意图像识别或施工验收。

填表顺序：
1. 现场负责人冻结参考版本、设备ID、米制占地、坐标方向与通道范围。
2. 模型作者确认对象ID对应关系，从实际世界网格取读数。坐标单位或轴向不同先校准，不把模型自填的bbox属性当实测。
3. 复核者逐台比较、点名差异和责任人。修改模型后重核；旧版本结果不能给新版本背书。

17列字段：
device_id / reference_version / model_version / units / frame /
ref_x1_m / ref_y1_m / ref_x2_m / ref_y2_m /
mesh_x1_m / mesh_y1_m / mesh_x2_m / mesh_y2_m /
status / issue / owner / evidence_path

status的含义：
PASS：只在已说明且有证据的检查范围内通过，不代表整厂可施工。
FAIL：已有可核不一致，例如错位、漏件或侵入指定通道。写清设备与通道编号。
UNKNOWN：无法建立对应关系或缺坐标、标尺、单位、方向、完整覆盖证据。不能伪装成通过，也不能把丢证据当成物理删除。

四组实际实验：
正常：7台已编号占位设备与参考XY一致且不侵入4条指定通道，限定PASS。
W1错位：在实际模型向东移动5.4m、向南0.3m；W1包络约[6.9,5.0,8.9,6.0]，侵入A-M，FAIL。
P2漏件：从模型实际删除P2后保存，7→6，FAIL。
W1缺坐标：仅删除导出清单中W1坐标字段，几何未删；UNKNOWN。

证据分层：本机Blender4.5.14读evaluated mesh世界顶点；3个保存模型另行重开复算；19项测试和25项集成核对通过。这些不是客户准确率或工程误差标准。
原参考西北内角为原点，x向东、y向南，单位米；Blender世界y显式反向转换。0.9m设备高度是展示假设。
未验：任意平面图识别、无编号模型的语义匹配、门墙/冷库/高度、作业净空、动线、消防/食品法规、真实客户项目和付费需求。
