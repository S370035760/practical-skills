# 原图到效果图：先填约束，再逐台核对

客户最容易遇到的问题不是图不漂亮，而是“图里的设备和通道，还是我原来的那一套吗？”这三张表用于把咨询输入与验收依据讲清楚，不提供自动优化或工程认证。

## 下载三张可填写表

- [需求与约束表](./requirements-intake.csv)：说明场地、输入版本、固定设施、工艺和此次决策。
- [逐台设备登记表](./equipment-register.csv)：每台设备一个唯一ID，对应位置、尺寸、朝向与资料来源。
- [16项交付核对表](./acceptance-checklist.csv)：把合理性、忠实还原、图像增强、真实模型与漫游分别核对。

用Excel、WPS或文本编辑器打开CSV。若中文乱码，请通过“从文本/CSV导入”选择UTF-8；数字列按需要设置小数精度，不要让软件自动改写编号。保存后重新打开，确认内容没有丢失。

## 先选模式，再谈图片

**新布局**：可以讨论并调整分区和设备位置，但要先明确工艺、尺寸与约束，确定方案版本，再据此出图。

**忠实转换**：已有平面图是依据；不要为画面漂亮默默移动设备和通道。发现原图有问题，另做带版本的建议，不把建议当原图还原结果。

这两种任务的验收标准不同。安全、操作和维修条件有疑问时，应指出并由适合的专业人员复核；不能把忠实复现错误布局称为“合理设计”。

## 怎样填写

1. 先填需求表。尺寸没有测量值就写未知/假设，不用视觉猜测冒充测量。
2. 设备表两行只是空白占位，不代表本案例有两台设备。逐台增加行并修改ID；例如一套货架的立柱、横梁和层板仍归属同一设备，不按网格个数计台数。位置为设备底面中心，长宽为设备局部轴向尺寸，旋转为从+x轴逆时针的度数；如果另用口径，先记录并统一转换。
3. 按范围使用核对表。未检查保持“未核”；核过才填“通过/不通过”；不在本次交付范围的项填“不适用”并说明。证据填脱敏文件名、截图或检查记录，不只写“AI认为通过”。
4. 保留输入、交付及修改记录的版本。2D、3D、效果图和视频分别说明实际包含哪些，不把计划输出当已交付。

## 本180㎡示例能证明什么

[原案例](./README.md)的实际输出是固定18×10m、六个指定功能区加中央通道的PNG/SVG，以及对此二维输出的说明视频。分区144㎡加通道36㎡等于180㎡。这些位置来自指定输入，不是模型自主寻优；2m通道也不是通用安全规范。

原图没有逐台设备坐标表，因此这次不从示意图臆造设备台数、型号或净空。本页新增的是待填写的沟通/核对资料，不是新增技能调用、3D模型、漫游或合规验收。核对表中的3D与漫游条目只在另行确认且实际包含这些交付时使用；不代表两款现有商品已自动串联支持它们。

隔离区只解决“放在哪里”的一部分问题；待检、检查结论及谁能放行还需要业务记录。图上颜色不能代替质量放行。
